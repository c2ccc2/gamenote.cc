为什么《黯井微光》攻略看起来像二十年前的网站

外观保留传统攻略站的阅读方式，底层仍然是一套现代网站。

SEP 26 · 2026

现代攻略网站通常有一套很成熟的设计方式。

大图、卡片、清晰的分类、响应式布局，以及越来越简洁的导航。

这些设计没有问题。

但在准备《黯井微光》攻略时，另一种已经很少见的网页形式重新变得有吸引力：

二十年前的中文游戏专题站。

那些网站按照今天的设计标准来看并不精致。

页面通常很窄。

左边是一长串目录。

章节标题可能只是醒目的红色文字。

攻略正文里夹着尺寸并不大的截图。

Boss、道具、魔法、地图，经常直接整理进彩色表格。

页面最下面甚至只是非常简单的：

“上一页｜目录｜下一页”

没有复杂动画。

没有占据整屏的 Hero。

也没有每隔几段内容就出现一张巨大的卡片。

但这种结构有一个非常直接的优点：

打开页面以后，很快就能知道这里到底有什么。

左侧从系统介绍一直排到流程攻略、地图、Boss、隐藏内容和收集要素。

目录甚至会显得有一点密。

但正因为这种密度，玩家在进入专题的第一刻就能形成一个非常明确的判断：

“这款游戏的资料都整理在这里。”

现在很多网站为了视觉简洁，会把越来越多的信息藏起来。

三个入口做成三张大卡片。

更多栏目收进二级菜单。

一屏只保留极少的内容。

作为普通网站，这可能更加现代。

但攻略站未必一定需要这样。

当一款游戏本身就包含大量地图、Boss、道具和隐藏内容时，信息很多并不需要被刻意隐藏。

攻略站真正需要解决的，是怎样让这些信息虽然很多，却依然容易找到。

因此，《黯井微光》的攻略会尝试重新采用一些传统专题站的设计方法。

例如固定在左侧的完整攻略目录。

明确而直接的文字链接。

以及：

★ 主线流程
◆ 重要收集
※ 注意事项
→ 下一步

正文也不会全部变成现代卡片。

流程攻略会继续以文章为主体，让游戏截图自然穿插在文字之间。

能够使用表格讲清楚的内容，例如 Boss 信息、道具位置、获取条件，也会直接使用表格。

页面底部则重新使用最简单的：

“上一页 / 目录 / 下一页”

这些元素保留了一部分传统攻略站的阅读方式。

当然，这并不意味着真的重新制作一个二十年前的网站。

字体不会小到难以阅读。

页面不会固定在只能适配旧显示器的宽度。

手机上，左侧长目录会收进独立的攻略菜单。

图片会自动适应屏幕。

宽表格可以单独横向滚动，而不会撑坏整个页面。

SEO、响应式、HTML 结构以及加载性能仍然按照现代网站的方式实现。

所以这套设计更准确的描述应该是：

“外观保留传统攻略站的阅读方式，底层仍然是一套现代网站。”

这套主题被命名为：

GAME NOTE CLASSIC

它并不只是为了怀旧。

更重要的原因是，这种网页结构本身就非常适合长篇游戏攻略。

当一个游戏拥有大量区域、Boss、收集和系统内容时，攻略站有时候就应该明确告诉玩家：

“这里的内容很多。”

同时也让玩家相信：

“想找的东西应该就在这个目录里。”

这种确定感，也是攻略体验的一部分。

《黯井微光》将作为第一款使用 GAME NOTE CLASSIC 的攻略。

它同时也是 GAME NOTE 从早期独立攻略子站，开始进入统一游戏目录结构后的第一批新内容之一。

新的技术结构，配上一种很旧的阅读方式。

也许这正适合一份游戏攻略。
