把《神之天平》的漫长旅程，整理成随手可查的攻略

新增《神之天平》攻略专题：让主线推进、回访收集与系统查询，各自有清楚的入口。

2026-10-21

攻略整理：GAME NOTE · 更新于 2026-09-27

《神之天平》加入 GAME NOTE 攻略档案。这次整理从已有的系列攻略出发，参考《卡赞》专题的目录与阅读方式，把漫长的流程拆成更方便查找的区域路线。

主线从天平洞窟走到终章，新章按重访区域继续展开。地图与宝箱、装备道具、嘉隆技能和天平系统分别建立查询入口；想继续推进剧情与想查一个具体物品，都能找到对应的位置。

整理时没有直接沿用原文的章节标题。比起把文章搬过来，更希望目录能回答玩家眼前的问题：现在该去哪里、机关需要什么、这一趟能顺路收集什么。图文步骤保留来源署名，并把宝石与首领索引链接回具体段落。

这次还补了元件宝石位置总表、按进度排列的易错过提醒，以及可搜索的首领索引。分支答案默认折叠，宝箱以位置表呈现，方便边玩边查。

专题首页尝试了深绿与古铜金的冒险手册风格：游戏场景作为开篇，章节卡片串起旅程，常用速查紧随其后。正文继续沿用 Classic 阅读版式，让长篇图文保持清楚。

现有资料没有覆盖的内容，继续留待补充。这份攻略会随着后续核对与勘误逐步完善。
