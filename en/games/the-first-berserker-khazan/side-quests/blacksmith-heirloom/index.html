The Blacksmith’s Heirloom

Guide editor: GAME NOTE

GAME NOTE CLASSIC · GUIDE LIBRARYThe First Berserker: Khazan

Speak to the blacksmith and return to the Spider Tomb.

01Spider Graveyard entrance: Soulstone and jar on opposite branches

Accept Blacksmith's Heirloom from Qazumaka and travel to Spider's Tomb.

The layout remains similar. Absorb the memory on the right platform.

  • Soulstone 1 · Location list
  • Jarling · Location list

At this fork, the left branch leads to a Soulstone and the right to a Jarling.

04Passage beyond the former iron gate: pass the giant bat and monkeys

Enter the nearby doorway, which was barred during the main mission.

Ambush the large bat hanging above.

Collect the memory inside. Guard against bats attacking from the left.

Clear the monkeys and open the chest on the right.

05Left of the Nexus: expose the false memory and search the Soulstone ledge

Continue to the Blade Nexus.

Go left. The memory ahead conceals a burrower, monkeys ambush nearby and a large bat hangs above.

  • Soulstone 2 · Location list

After clearing them, find the Soulstone on the left platform.

07Tree-root shortcut and Belius the giant bear

Absorb the memory at the pictured location.

Use the roots to open a Nexus shortcut, then approach the boss.

Berius is a giant bear with the same general moves as wild bears. Apply the earlier bear strategy.

08Hengie atop the post-battle stairs: return the heirloom and unlock crafting

Climb the stairs after the fight and speak to Hengie before returning.

You return directly to Qazumaka. Completing the mission unlocks equipment crafting.
