# 神之天平攻略内容与构建

入口：`/games/astlibra-revision/`。沿用卡赞 Classic 的双栏、分组折叠目录、正文配图、页内步骤、图片放大与前后篇导航。

## 本地资料如何融入

用户提供的六篇 faili0802 攻略作为导入来源，源目录只读。正文、截图与署名一起保留；文章索引、封面、上／下篇导航与作者完结感言不进入玩家流程。本站按地点、行动目标、获取条件和查询用途重新组织标题，不能把源 Markdown 的标题层级直接当网站目录。

- 主线按天平洞窟、湿地、火山、渔村、魔王城、雪山遗迹、返乡、未来都市和铁娘子组织；第六章跨越原来的上下篇，合并为连续图文。
- 新章按重访区域拆为九篇，含幻梦、盖亚与爱情事件。小百和时间分歧另设查询入口，回链到对应流程。
- 地图与宝箱按探索阶段整理，共 104 条位置记录。奖励名称仅使用来源明确列出的信息，其他条目使用当地宝箱编号；编号在不同阶段独立，不能当全局唯一 ID。
- 嘉隆以用途分为八组，96 项技能采用正文展示配置消耗、来源和效果。
- 天平、小徽章兑换、斗技场及配方转换为查询页面和原生表格；装备及道具的属性资料原本就是图片，保留为可放大的图表，不伪造未经转录的物品数据。
- 使用 387 张独立本地图片，共 388 处来源配图。攻略来源与图片水印保留在正文／文末；不在每张图片下重复堆放来源链接。

## 数据与脚本

- `source-content.json`：六份规范化文档，保留正文块顺序、原文件行号、来源 URL、图片尺寸与 SHA-256。
- `source-index.json`：文档摘要与图片引用计数。
- `source-signatures.json`：阅读边界对应的源文档签名；导入文档变化后构建会失败，必须检查边界再更新签名。
- `layout.cjs`：人工划定主线和新章阅读段落；每个段落有稳定 ID、玩家导向标题和来源范围。
- `reader-copy.cjs`：清理作者日记、玩笑、断句与明显文字错误的逐段调整；原始归档不受影响。
- `scripts/lib/astlibra-guide.cjs`：把来源、阅读段落、装备分类、嘉隆、系统、宝箱和人物事件归一化，建立互链。
- `pickups.cjs`：保留前一版四个剧情物品入口的锚点，不参与 104 条宝箱计数。
- `scripts/import-astlibra-local.cjs`：导入用户的本地目录，按图片内容哈希复用素材并读取尺寸。构建不依赖原始绝对路径。
- `scripts/build-astlibra.cjs`：生成 76 页、来源列表、搜索元数据与站点地图条目。
- `scripts/verify-astlibra.cjs`：检查来源配图覆盖、文件完整性、宝箱和技能数量、跨篇连续性、目录状态、锚点及本地链接。
- `assets/astlibra.js`：宝箱关键词与类型筛选。位置表使用普通编号，不设置勾选或完成进度。

重新导入：`node scripts/import-astlibra-local.cjs --source "本地攻略目录"`。输入目录应含六篇 Markdown 与 `images/`。不执行源目录内的抓取脚本，不在源目录写文件。

构建：`npm run build:astlibra`。会定向更新本专题、图鉴入口、攻略列表、统计标记及站内搜索。完整构建也包含本专题；常规校验使用 `npm run lint` 与 `npm run typecheck`。

## 已知资料边界

内容适用本体 Revision。新章是本体追加内容，不与《外传：幻雾之洞窟》混用。

本地资料提供五名隐藏首领的具体入口；战神杰拉丁仅有文章跳转，未据此推测其位置。未提供独立全成就清单，相关页面只指向实际收录的事件和路线。配方中两条疑似名称错误的行已明确标注，以游戏内配方为准。

当前是按用户资料完成的内容整合，未声明全部数据已在游戏内逐项实测；装备图表内文字尚未转为逐物品的可搜索数据库。中文攻略接入中英文图鉴时，英文图鉴直接链接现有中文专题，避免生成不存在的英文攻略地址。
