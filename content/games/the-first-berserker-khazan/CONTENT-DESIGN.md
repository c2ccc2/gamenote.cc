# 《第一狂战士：卡赞》攻略内容结构

## 阅读目标

这是完整的游戏攻略资料库，不只是任务流程。玩家可以按眼前的问题进入主线、支线、首领、装备、系统、人物或收集资料；具体位置、数值和招式只在核验后写成确定说法。

## 页面层级

1. **攻略首页**：游戏资料、八类栏目、已收录的基础资料卡与资料状态。栏目数据见 `library.json`，起始条目见 `entries.json`。
2. **主线与支线**：按任务顺序列章节；未完成章节只显示标题和整理状态，不生成空详情页。支线按接取条件与关联主线排序。
3. **首领图鉴**：首领所在任务、招式起手、应对、奖励与关联章节。首章雪魈王先链接到流程中的战斗笔记。
4. **武器与装备**：按刀斧、巨剑、长枪及套装分类；单件条目记录属性、套装效果、获取地点、版本与实机核验状态。
5. **技能与系统**：防御、精力、技能树、幻影形态等机制；按解锁时机与实际用途组织。
6. **人物与 NPC**：角色关系、出场章节、交互功能及关联任务。剧情内容应标记剧透范围。
7. **收集与档案**：剧情物品、鬼石等按名称和任务双向检索；全收集数量须实机核对后才标注。
8. **成就与挑战**：成就条件、关联章节、多周目与挑战模式。未有可靠资料时仅保留栏目规划。

首领、装备、系统、人物与收集现各有独立的中英文目录页，首页保留跨栏目入口。支线与成就仍在规划状态；单件装备或单个角色的独立详情页等资料足够深入时再生成，避免一两句话的空薄页面。

## 每章采集清单

| 内容 | 记录方式 |
| --- | --- |
| 起点、终点、关键路径 | 用玩家可辨认的地标与互动对象描述；配本站自制路线图或实机截图 |
| 存档点与捷径 | 说明开启前后的方向，以及何时适合返回整理装备 |
| 剧情物品与收集 | 名称、取得时机、位置线索、是否已实机核验；不将零散线索称为全收集 |
| 首领 | 开战准备、明显起手、应对窗口、常见失败原因；按实际游玩核验 |
| 来源与版本 | 参考页面、游玩平台、游戏版本、核验日期；资料修订时同步更新 |

## 首章样稿范围

《被流放的英雄》当前已提供路线速览、押送令提示、推车捷径与雪魈王的基础应对。它是原创摘要，不是全收集或逐屏图文攻略。下一轮实机记录应优先补齐存档点之间的地标、其他可拾取物、雪魈王不同阶段的招式与本站自制图片。

3DM 文章仅作事实线索与来源链接。其正文和截图的转载需要另行取得授权；本站原创攻略可独立继续制作。
