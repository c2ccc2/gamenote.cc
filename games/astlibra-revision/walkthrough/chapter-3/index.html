火山探索：悬石机关与羽毛靴

攻略整理：GAME NOTE · 更新于 2026-10-22

GAME NOTE CLASSIC · GUIDE LIBRARY神之天平
ASTLIBRA
Revision

按区域图绕行火山，用回旋镖开路，取得羽毛靴后穿越岩浆。

  1. 回访旧区域并领取遗物任务
  2. 与白会合，击落悬石开路
  3. 挑战守护兽，取得羽毛靴
  4. 回收卷轴与岩浆后的宝箱
  5. 取得挂盘，挑战火之魔神

01回访旧区域并领取遗物任务

可以传送会以前章节的装置

家中间的门可传送到之前的章节。任务出发前可回访；若暂时无法进入，先推进当前剧情，再在与弥露确认出发前尝试。旧区域初始位置的传送阵可以返回自己的房子。火山区域编号见本页路线图。

与弥露对话后回家推进剧情，房间右侧的门会打开。前往酒馆领取回收遗物的任务，再次对话即会出发，先完成补给。

02与白会合，击落悬石开路

长剧情结束后主角出现在区域1，按照地图从区域1➡区域2➡区域7➡区域8发生剧情，之后前往区域9向右走发生剧情，结束后白成为同伴。

从区域9➡区域10➡区域11➡区域16，来到最左边有个大坑，用二段跳边向左侧靠边下落，到最后会落到一个平台上，向左来到区域21发生剧情图2。之后前往区域25见到盖乌发生剧情得到木制回旋镖。因为区域20和区域22都无法向上移动，接下来需要从区域15开始绕一圈返回区域21。在边缘使用刚才得到的木制回旋镖后石头被击落，跳下去出现了可以向左边前进的平台。前往区域23存档后进入区域24开始BOSS战。

03挑战守护兽，取得羽毛靴

BOSS战很简单，可以利用远程主角空挥普通攻击出发白放魔法来攻击BOSS。BOSS的魔法都可以用防御格挡，出现满屏幕向右慢速平移的魔法不会躲的话，可以走到最右边防御，一般都可以防住。胜利后得到天马的羽毛靴，这是个饰品，装备上可以免疫地形伤害，这样就可以在岩浆上行走了。

04回收卷轴与岩浆后的宝箱

返回区域2，在图4的位置下去，因为下面有宝箱，得到反击的奥义卷轴，继续向左到达区域5发生剧情。

前往区域8，图5位置有个绿色向上箭头，在上方会出现宝箱，从右边墙壁可以跳上去。前往区域9向右边走发生剧情，剧情后有大宝贝商店，准备充足后出发。

05取得挂盘，挑战火之魔神

前往区域11，这个区域因为现在可以走岩浆了，左边下方岩浆可以前往区域16，打破左边的墙壁可以得到天平挂盘图6，7。捡完宝箱后前往区域25，向下的道路已经打开了，准备充足以后前往区域26，走到最右边下去到达区域27发生剧情进入BOSS战。这个BOSS非常的难，乍看一下以为是火属性，其实它是暗属性，可以用圣属性凭依攻击。

BOSS一共分为2个阶段，第一阶段开始身体周围会被圆形火焰包围，不能触碰，并且会顺时针向主角放火球，这个节奏自己找一找吧，不是太好躲。等它放完顺时针火球后圆形包围火焰会消失，这个时候可以贴身输出，要站在BOSS中间的位置，因为四周还是会放出火焰，但BOSS本身没有伤害判定。输出一定时间再次变成圆形包围火焰，这时候要远离，BOSS会放个新的技能，用二段跳和防御来回避，然后就是反复切换。

第一阶段打到一定血量后进入第二阶段，先是会放激光散落一地的小怪，主角需要边清小怪边打BOSS，就第一阶段来说第二阶段比较简单（附带一句，玩家中技能太多会有出血状态，这个时候很难回血，合成配方里枸杞和小空瓶合成的药瓶使用时间很短，如果中出血状态了用药瓶来回复，使用时机就是出血伤害出现的瞬间使用，要不然时间也不够）。胜利后在自己家醒来，前往酒馆见到盖乌和弥露，剧情后第三章结束。
