湿地救援：采药、石板与哥布林据点

攻略整理：GAME NOTE · 更新于 2026-10-21

GAME NOTE CLASSIC · GUIDE LIBRARY神之天平
ASTLIBRA
Revision

从公会运送委托出发，帮助老夫妇，利用泊灵的嗅觉破解入口。

  1. 加入公会并完成出发准备
  2. 找到兽道与湿地小屋
  3. 避开滚石，取得特效果实
  4. 寻找笔记与石板碎片
  5. 进入据点，完成头骨问答
  6. 准备连续两场首领战

01加入公会并完成出发准备

剧情后来到力斯帕达尔镇，向右走到尽头进入酒馆与酒保对话加入公会并得到不明钥匙。出酒馆走进武器屋旁边的门后往左边走进自己的房子休息，醒来先与在睡觉的乌鸦对话后出房子追随黄发少女发生剧情。等再次醒来去酒馆与弥露对话会有运送的任务交给主角，再次与弥露对话任务就会开始（任务开始后是不能返回的，所以在去之前可以打打怪练练级准备充足的物资再出发，这个时候也可以去竞技场）。

02找到兽道与湿地小屋

开始任务后向右一直走见到盖乌图1，剧情后向左返回剧情出现一条新的路图2，进入后上方有个大宝贝商店，里面有卖道具和装备，还有扭蛋机，使用小徽章就可以扭蛋图3。

向右走需要使用火把，走到图4位置，左边的高台可以用二段跳上去，往左边走打开宝箱得到升剑的奥义卷轴，按住上再按住攻击可以发动，其实按住攻击再按上反过来也可以发动升剑（二段跳是在菜单嘉隆➡探索性➡空中跃动），继续向右走到达老夫妇家发生剧情。

03避开滚石，取得特效果实

剧情后按原路返回，又再次碰到泊灵图5，对话后主角决定返回老夫妇家。到达老夫妇家与躺在床上的老奶奶对话得知老爷爷出去采药了。出房子跟随泊灵向右走，下一个场景会出现连续滚石，推荐使用二段跳跳过滚石部分，然后发生剧情碰到盖乌，剧情后主角要代替老爷爷去采药。

向右切换场景马上进入团战，胜利后调查上面的道具图6，获得特效果实。返回老夫妇家（返回时已经没有滚石了）剧情后主角准备返回城镇。中途再次碰到泊灵，还要再次返回老夫妇家，好在这次有传送阵可以直接传送图7。剧情后向右走这次变成普通战斗区域了，前进到有存档水晶和大宝贝商店的场景。

04寻找笔记与石板碎片

走到场景右上方发生剧情，主角需要利用泊灵的嗅觉找到门的钥匙。当主角靠近钥匙的时候泊灵头上就会显示叹号，找到钥匙位置时主角会显示可以互动，如上图8先找到笔记得知钥匙被分散扔掉了。

返回到第一个大宝贝商店的场景往左上方走如上图9，10可以捡到2个石板的碎片，打开道具➡合成配方第4页把2个碎片合成，获得哥布林的石板。仔细看本场景左上方有个绿色向上箭头，移动到箭头上按上方向键会出现隐藏宝箱。

还有一个道具是在一开始来到湿地碰到盖乌的湖边场景（有可以传送到老夫妇家传送阵的场景一直向右），在图11位置可以见到环境卡。

05进入据点，完成头骨问答

再次来到第2个大宝贝商店场景，在右上方打开菜单➡道具找到刚合成好的石板使用后发生剧情，进入哥布林的据点。进入后第1个场景如图12位置有个绿色向上箭头，按住上方向键左下角会出现隐藏宝箱，从宝箱的右侧跳进墙壁里打开宝箱得到天平挂盘。一直向右走来到一个解谜的场景，先调查金色台座然后取得左边木头骨。

返回老夫妇家使用传送阵后向右来到湖边场景，把木头骨丢进湖里，会出现一位女子问你丢了什么，正确答案是木头骨，如果回答金或者银可以返回大宝贝商店买回木头骨。

06准备连续两场首领战

重新返回哥布林据点（这里说明一下，推荐单独存一个存档，之后有2个BOSS战，如果打不过可以读回这个存档练练级强化以后再进去），分别使用木头骨和金头骨发生剧情。继续前进有存档水晶，剧情后就进入BOSS战。BOSS有2种咏唱方式放魔法，一个是扩散的麻痹弹一样的魔法，一个是6连快速向前的光波一样的魔法。

麻痹弹用防御可以防住，但注意不要防住一个就松开防御，因为比较密集，主角有可能短时间多段被击中，所以要注意。快速光波魔法有两种回避方式，如果你单纯的防御有可能撑不到最后一发就破防了被击中很疼，这里可以使用原地二段跳➡防御➡原地二段跳➡防御➡原地二段跳➡防御这样来抵挡6次魔法，如果你是站在中间的高台，6次可以完全用原地跳来回避。

至于攻击机会可以用武器的蓄力远程攻击结合火龙魔法来慢慢削血，不要贪刀，被打一次挺疼的。

胜利后有存档水晶和大宝贝商店，返回发生剧情再次BOSS战。这次的BOSS比较简单，也是2种咏唱魔法，一个是3连石化魔法，一个是扩散魔法。石化魔法完全用防御可以抵挡，扩散魔法可以在它咏唱的时候跑开再防御。其他物理攻击看准时机防御就好，至于输出方法大家各自用自己习惯的方式打就可以了，比较简单。胜利剧情后出房子出现传送阵，向左返回碰到盖乌发生剧情，第二章结束。
