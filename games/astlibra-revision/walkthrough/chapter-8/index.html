未来都市与研究所：传送点、终端和门卡

攻略整理：GAME NOTE · 更新于 2026-10-22

GAME NOTE CLASSIC · GUIDE LIBRARY神之天平
ASTLIBRA
Revision

解锁都市传送点，按顺序调查研究所终端并取得失重奥义。

  1. 突破机动兵器并进入东京
  2. 取得世界树之花并返回整备
  3. 逐段打开三个战区传送点
  4. 黑色机体与大佐战
  5. 调查研究所终端并打开捷径
  6. 击败反射敌人，取得门卡
  7. 用门卡取得失重奥义
  8. 解锁深处并完成三连战

01突破机动兵器并进入东京

剧情后一直向右走发生剧情，主角来到了未来，一直向右走进入BOSS战。白色的机器人和之前技能是一样的，场地比较大先把白色的分离出来，血量也很少。黑色的技能都是白色的进化技能，在天空中向下放冰的技能非常疼，这个建议站在原地用后撤的无敌时间来躲比较好，不要贪刀，它放完一次并跳起来打两下等待下一次回避，一次技能要放3次冰。

战斗之后向左会出现杂兵，机器人看着很多其实他们的数值好像还停留在第四章，打人并不是很疼，但坦克不一样，先注意消灭坦克，继续向左发生剧情。再次发生BOSS战，这次直接向左逃走切换场景，有存档水晶，在中途有可以进入隐藏通路图1，下去发生剧情。

02取得世界树之花并返回整备

剧情后主角来到了东京，见到了阿凯，对话后进入自由时间，往回走会有传送回城镇的装置图2，前往酒馆不要进去，跳到房子上面向右走打开宝箱得到世界树之花图3，这个道具可以更详细的回到以往的地点，就是个传送道具，也可以直接传送回力斯帕达尔镇，如果有要刷的装备可以现在回去准备了，也多准备一些止血药剂和血清最后BOSS的时候要用。

03逐段打开三个战区传送点

与阿凯对话选择“是”开始任务。一直向右走第二个区域如果可以全灭敌人会出现宝箱图4，下一个区域刚走两步进入BOSS战。这个贴身打基本上没什么难度，和BOSS站垂直就可以了。切换区域刚开始会有闪光的地方，可以解锁传送点第1地点图5，这里建议传送回去向左走返回存档水晶存个档，返回战斗区时需要和阿凯对话。

传送到第1地点继续前进，第2个区域有绿色向上箭头图6，再走到第3个区域进入BOSS战。注意BOSS的锁定技能，当主角被锁定时马上闪开，BOSS会对锁定的位置连续射击，别的技能都可以用防御。胜利后解锁第2地点，还是一样回去存档。

传送到第2地点继续前进，第1个区域下面有一个宝箱，在图7位置可以下去，一直向右打开宝箱得到天平挂盘。继续前进再次进入BOSS战。这个和之前的差不多，建议优先清小怪，BOSS的导弹不可以防御。

04黑色机体与大佐战

胜利后终于出现存档水晶，前进进入BOSS战。地狱级的难度，开始先和之前的3体黑色的机器人战斗，基本上满屏幕的冰块，导弹，镰刀，可参考下面的应对思路。准备好止血药剂和药瓶，如果使用速度够快可以不用准备药瓶，开始直接使用止血药剂，这样就算被砍了也不会有出血状态，之后左右挑一边角落，基本就站在角落打，因为有的机器人放冰块它的手会伸出战区这样可以避免冰块，其他的该防御的防御或者跳跃回避导弹。

主要的输出手段是风属性的乱射和圣属性的天使凭依技，非常好用，没有的话可以回去刷刷小怪成长多点一点，可据此调整配置。

这3个打完以后并没有结束，还要BOSS连战，战斗开始不要犹豫直接BOSS贴身，它的激光炮中了基本就死了然后你还要从刚才那3个机器人开始打，这个BOSS有个烟雾的技能会画圈扩散，中了的话会失明，就算中了记得听声音，激光炮放之前会有声音，听到声音就算看不见也要冲过去，其他的会有向前方的机枪射击，注意防御就好，这个BOSS并不难，如果真的实在过不了的就把游戏难度给调到最低吧，确实太恶心了。

05调查研究所终端并打开捷径

战斗胜利后向右进入研究所见到名云，剧情后有存档水晶和大宝贝商店。继续前进乘电梯后向左，这个区域有两个方向可以走先走左边先不下去，一路前进最后发现一个电脑，调查电脑发生剧情某处被解锁了，站在图8位置按圈还是上会出现个宝箱。从右边出去下来又回到刚才的地方，下去又发现一台电脑调查后某处被解锁了。

回到中间的电梯，乘电梯这次从右边走，切换区域向右直走，这个区域敌人非常的变态，建议就站在门口打先别去招惹红色的螃蟹。一本道一直走中间经过一个有闪现平台的地方向左，调查电脑捷径门被打开图9。进捷径门下来再去右边打破中间的石头下去，下面是岩浆地带建议换上天马的羽毛靴，向左前进调查电脑某处被解锁了。

06击败反射敌人，取得门卡

向左前进再次乘坐电梯进入右边，这次向上走进中间捷径门，再向左发现存档水晶。继续前进进入BOSS战。这个BOSS比较简单，注意它的反射就可以了，反射的时候伤害会反弹给主角，别的基本上都是老套路。胜利后继续向左调查电脑后发生剧情，向左前进再发生剧情，阿凯离开了。向右返回发生剧情，剧情后得到门卡。

07用门卡取得失重奥义

得到门卡后先去电梯上面左边的门也就是第一开始开的2台电脑的地方，进入后向上走再向右走会看到一扇红色的门，打开菜单使用刚才得到的门卡打开红色的门，进入后打开对面的宝箱得到失重的奥义卷轴。

08解锁深处并完成三连战

返回电梯的最下面右边有一扇红色的门，使用门卡进入，切换区域发现电脑，调查电脑发生剧情某处被解锁了。返回电梯上面进入右边再向上进捷径门，一路向左走路已经通了，乘电梯上去有存档水晶和大宝贝商店。向右走进入BOSS三连战（BOSS战之前准备好止血药剂和血清，尽量多准备一些，还有回复药），第一个BOSS注意左右两个元素要打掉才可以给与伤害，顺序是优先打左边的，没有什么难度。

第2个BOSS，当中间天平有花的时候无法给与伤害，要时刻注意中间的天平，而且还有一点很重要，这2个BOSS几乎要同时打死，如果先打死一个另一个会进入类似狂暴模式，血量调节要做好，止血药剂和血清是在这个BOSS使用，至于BOSS的技能小刀和黄色的光波无法防御，别的大家自己摸索吧，会打了以后也不是太难。

胜利后发生剧情继续第3个BOSS，所有属性的技能都有，先摸清套路，如果在打这个BOSS的时候感觉满屏幕都是子弹建议跑远的离开，凭依技乱射在这里非常好用。胜利后向左走出现职员表，也相当于一个暂时的结局吧，第八章结束。
