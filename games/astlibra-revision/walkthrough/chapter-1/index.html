天平洞窟：火把、宝珠与金龙

攻略整理：GAME NOTE · 更新于 2026-10-22

GAME NOTE CLASSIC · GUIDE LIBRARY神之天平
ASTLIBRA
Revision

完成村庄委托，制作火把，交换宝珠后取得天平。

  1. 接取村庄委托
  2. 收集木柴与松脂，制作火把
  3. 沿下层进入洞窟，取得蓝色宝珠
  4. 交换宝珠并打开深处通路
  5. 攻击金龙头部并取得天平

01接取村庄委托

片头动画结束后一条路前进发生剧情，结束后第二天醒来前进来到村子得知村子尽头有一个天平洞窟，与第一个房子里女性对话选择“否”得知她父亲为了救小女儿去洞窟已经一周没有回来了，于是主角决定前往洞窟去找她的父亲，对话后得到圆盾。

02收集木柴与松脂，制作火把

为了去洞窟主角需要火把，与道具屋对话后需要收集制作火把的素材木柴捆和松脂。到村子右边的酒馆与所有NPC对话得知木柴捆可以在洞窟开始的地方得到，如上图1在洞窟第一个画面右下方可以得到木柴捆。刚才在酒馆对话还得知主角要去找的那位父亲是个雕工匠可能会有主角需要的松脂，再次进入村子第一个房子与大女儿对话后需要去湖边才能得到松脂。

从左边出村一路走会到达湖边，游泳教学后主角向右走通过湖水发生BOSS战，BOSS战之前会有一个简单的技能系统的讲解，讲解完并战斗胜利后调查右边的道具得到松脂。现在两个需要的素材都到手了，与道具屋对话后得到3个火把和合成配方，现在开始已经可以在道具屋购买火把了。

03沿下层进入洞窟，取得蓝色宝珠

准备好火把就可以进入洞窟了（注意：使用火把是有时间限制的，一段时间后火把就会灭掉，建议多准备一些，如果买不了太多可以打打怪攒点钱买）。

在洞窟探索会走一个有上下分叉门的房间如上图2，先从下面走（注意如果不小心先走了上面并且捡了红色水晶球导致返回时被墙挡住不知道怎么办了，可以返回捡到红色水晶球的地方，在台座前打开菜单选道具使用红色水晶球就可以恢复）再前进会来到一个头顶有刺的机关房间图3，先不用动等头上的刺快扎到主角的时候发生剧情快速进门。

04交换宝珠并打开深处通路

剧情后继续前进来到有回复水晶还有蓝色水晶球的房间，调查并取得蓝色水晶球图4，并且房间右上角的房间可以得到后撤奥义书。重新返回图2的房间从上面的门进入，在左下方取得红色水晶球图5，然后打开菜单选道具使用蓝色水晶球放到台座上，之后返回村子。

返回村子走到有水的地方发生剧情，身上的红色水晶球变成了蓝色水晶球。到村子第一个房子与大女儿对话后重新返回洞窟前往第一次取得蓝色水晶球的房间图4，在左边台座前使用蓝色水晶球后右边会出现大门图6。

05攻击金龙头部并取得天平

进入房间开始BOSS战，BOSS只有击中头部才有伤害，如果头部太高可以按住上方向使用蓄力攻击，BOSS的全部攻击都可以用盾牌防御，注意别过度防御是的防御槽空掉掉血就可以。

战斗胜利后得到阿斯特赖亚的天平和传奇道具天平挂盘图7，菜单开启天平系统。返回村子已经变了样子，调查第一个房子的门发生剧情。剧情后从左边出村子碰到了刚开始遇见的盖乌，第一章结束。
