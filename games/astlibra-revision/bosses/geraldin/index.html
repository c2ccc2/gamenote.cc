斗神杰拉丁：火山入口与限时战

攻略整理：GAME NOTE · 更新于 2026-10-22

GAME NOTE CLASSIC · GUIDE LIBRARY神之天平
ASTLIBRA
Revision

从火山隐藏入口挑战守卫与杰拉丁，核对胜利奖励。

火山入口与挑战时机

第三章火山内传送后，从剧情起点向左一个场景，再向下一个场景；破坏该场景右下角岩石，进入后方区域。可先继续主线成长，再回来挑战。

先过守卫，再处理限时战

先击败两名守卫。首领的拔刀是高伤多段攻击，看到招式提示及时回避，或用合适的防御与凭依技时机处理。第五次拔刀后的终结技会强制结束战斗，应在此之前击败首领；持续超时先提升输出。火属性可用于这场战斗。

胜利奖励与后续查询

奖励：里迪尔、等级勋章。不要将“第三章开放”理解成第三章必须击败。
