再入研究所：返乡收集与终端重启

攻略整理：GAME NOTE · 更新于 2026-10-21

GAME NOTE CLASSIC · GUIDE LIBRARY神之天平
ASTLIBRA
Revision

利用自由活动先回访故乡，再重新打开研究所道路。

本页涉及后续剧情与结局分支，建议到达相应进度后再阅读。

  1. 先回故乡取得蜕变元件
  2. 突破都市战区并挑战大佐
  3. 重开终端，回收体力元件
  4. 完成研究所的连续首领战

01先回故乡取得蜕变元件

刚开始有存档水晶，向左走经过电视的区域进入BOSS战。3台黑化的白色机器人，没什么难度注意多用防反涨精力用凭依技输出。胜利后继续前进有一些杂兵，再向左走有存档水晶，还是和之前一样进入秘密通道图20。

向下走见到名云发生剧情，剧情后从右边出宿舍一直走见到阿凯，剧情后先不要和阿凯对话,向左走有传送装置，先传送回家里，然后选择传送回故乡阿涅斯塔，传送完向右走墓碑前面闪光点取得“元件宝石【嘉隆蜕变】”图21，然后向左走回村子再向左边前往森林，一直前进直到有存档水晶，然后进门再一直向右走地上有闪光点取得“元件宝石【凭依技蜕变】”图22。

02突破都市战区并挑战大佐

返回东京继续拯救世界，与阿凯对话开始任务。这里和之前的第八章是一样的，3个小BOSS，每打一个都会解锁一个传送点。最后是大佐+2台黑色黑化机器人，这个比较难，大佐这次可以不用靠近可以用失重的奥义来回避开始的激光炮，战斗前要准备一点止血药剂和眼药水防止出血失明。战斗胜利后向右一直走进入研究所。

03重开终端，回收体力元件

研究所虽然红色的门有门卡可以开，但是需要电脑解锁的门还是要解锁，坐中间电梯到上面左边有上下两台电脑还有右边有一台（在开启右边电脑的同时换上天马的羽毛靴在下方岩浆里面有个闪光点取得“元件宝石【体力】”图23）和一个捷径门的开关。三台都开完之后进入电梯上面右边的第一个区域上去进门向左有存档水晶，再向左走发生剧情，切换区域进入BOSS战。

这次是2个老朋友同时出现，注意不要在2个中间就可以，波动也没有什么威胁。胜利后继续向左有存档水晶，调查大电脑解锁设备，再向左切换区域进入BOSS战。这次是4个BOSS一起打，其实也没有多难，激光多的时候跳起来用失重回避，当满屏幕子弹无处去的时候可以用盾冲冲出去。

04完成研究所的连续首领战

胜利后向右返回，进入捷径门，下去再向左返回电梯，坐电梯下去进入右边红色的门来到一片水的区域，向右切换区域调查电脑解锁，再返回坐电梯走右边上去进捷径门一直向左，坐电梯上去有存档水晶和大宝贝商店，向右走和之前一样是BOSS三连战，前2个BOSS和之前是一样的正常打就可以，第3个BOSS技能其实也没有太大的变化，喷火的时候是一圈可以用三段跳绕身后输出，整个BOSS战输出机会不太多，因为满屏幕的泡泡，多走位防御找机会吧。

战斗胜利后得到阿努莉斯的大脑和玻璃金属板。剧情之后返回酒馆，再回家发生剧情。
