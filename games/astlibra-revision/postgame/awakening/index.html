重新启程：幻梦与洞窟强化

攻略整理：GAME NOTE · 更新于 2026-10-22

GAME NOTE CLASSIC · GUIDE LIBRARY神之天平
ASTLIBRA
Revision

从终章存档继续，回到边境并开启装备强化与天平强化。

本页涉及后续剧情与结局分支，建议到达相应进度后再阅读。

  1. 离开幻梦并重新遇见嘉隆
  2. 回到边境，开启装备强化
  3. 进入洞窟，开启装备盘
  4. 再次挑战金龙，强化天平

01离开幻梦并重新遇见嘉隆

读取存档主角在家里醒来，前往酒馆发生剧情，再次回到家里和阿努莉斯发生剧情，然后主角在草原上醒来剧情后对着嘉隆打开菜单使用安眠药发生剧情，再次醒来主角在酒馆，向左出酒馆来到幻梦，有存档水晶。

切换区域因为嘉隆不在所以放不了凭依技，向右切换区域后发生剧情嘉隆出现了，还有存档水晶。向下前进，再向下切换区域进入BOSS战。这个BOSS很简单，站在它的正下方如果穿的刚才最后BOSS的装备防御格挡完全没问题，有一个骤雨的技能是先划线看准划线别站在划线的位置，等全部划完会按照刚才划的线放激光，记住位置其实很好躲。然后继续BOSS战。

也一样很简单，如果有圣属性的天使凭依技的话可以站在最边上单个杂兵输出，这样天使每一次都可以打到所有敌人。

02回到边境，开启装备强化

战斗胜利后回到了整个故事的最开始，出房子向右走发生剧情，醒来后去最右边捡起地上闪光得到“原件宝石【幸运】”图1，然后返回存档水晶向左走，切换2个区域见到盖乌发生剧情，左上方有个靶子，用弓弩射中打开宝箱可以得到魔导水晶。新章里面宝箱的外观也发生了变化，但用的钥匙不变图2，一直向右走到达佩可奇拉村发生剧情，剧情后提示武器店追加强化装备服务和嘉隆之书追加了强化装备的页面图3，还有存档水晶。

向右前进捡到佩可奇拉滴露，继续前进进入洞窟。

03进入洞窟，开启装备盘

刚进洞窟就开启新的系统“装备盘”图4，可通过装备盘继续强化装备，通过宝箱可以获得，在换装备的时候多了一个编辑装备盘的选项。继续前进有岔路的地方先从上面走，里面地上有个闪光点，可以得到“原件宝石（武器属性）”图5，返回从岔路下面走进门，发现存档水晶。进入左边的门进入BOSS战。

BOSS有个波动的技能，会把主角从中间向两边吹并且两边设置了魔法球碰到会有伤害，当看到屏幕上面出现波动词条时可以直接跳到最左边魔法球里面有一个很小的空间，这样就可以完全回避了，而且不要离BOSS太近，一般放完波动都会放一个水魔法，如果离太近会看不到就中招了，别的没什么需要注意的了。

04再次挑战金龙，强化天平

继续前进切换2个区域发生剧情，有存档水晶。进门进入BOSS战。BOSS技能被强化，嘴里持续吐3个方向的火，如果主角靠近它的左手会持续的巨大范围爪击，还有一个蓄力喷火球的技能。基本是靠近输出有精力了就用风属性凭依技，防御格挡要高，如果想靠回避的话比较困难不受伤，BOSS蓄力时可以远离慢慢防。战斗胜利后进门又得到一个天平，于是天平得到强化，挂盘可以用5W金币强化图6。
