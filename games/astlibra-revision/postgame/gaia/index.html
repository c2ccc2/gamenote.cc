盖亚迷宫：同行伙伴、随机楼层与最终连战

攻略整理：GAME NOTE · 更新于 2026-10-21

GAME NOTE CLASSIC · GUIDE LIBRARY神之天平
ASTLIBRA
Revision

带同伴进入盖亚，寻找每层开关并挑战最后的五连战。

本页涉及后续剧情与结局分支，建议到达相应进度后再阅读。

  1. 开启友好度并带同伴同行
  2. 寻找每层开关并使用楼层传送
  3. 最终连战前完成整备
  4. 处理杂兵与同伴属性支援
  5. 优先处理持剑手与十字激光

01开启友好度并带同伴同行

前往酒馆发生剧情，之后转回自己家，增加一个新系统“友好度”，提升同伴的友好度可以每个同伴得到2个爱情，每交给阿努莉斯一个爱情她的记忆就会恢复一点图24。再次前往酒馆发生剧情获得传送石，再次与弥露对话开始任务。剧情过后有存档水晶，这里的敌人都是随机的不一定是哪一章的敌人，一直向右走都是战斗区域而且难度很高谨慎前行，切换几个区域出现存档水晶。

剧情后出现传送阵，这个可以直接传送到酒馆，现在可以去酒馆带一名同伴来一起战斗图25。返回酒馆多了一个房间里面有存档水晶和大宝贝商店，向左走同伴们都在，与同伴对话角色下面会出现像好感度一样的计量槽，一起战斗就可以增加好感度图26。

02寻找每层开关并使用楼层传送

选择一位同伴一起前往盖亚，盖亚构造是随机的，而且每一层需要找到开关才能前往下一层。

每一层左上角写着当前大层和小层的层数，例如1-2、3-4，数字左边紫色的球表示还没有打开开关，开关是一个植物里面的宝珠，34大层会换成现代科技风格，每个大层都有6小层，第6小层是BOSS战图27，每次BOSS战都是2个随机的BOSS，战斗胜利后会有5个随机的宝箱，这宝箱里也可以得到爱情图28，开完宝箱切换区域有个蓝色的水晶球，调查水晶球可以返回酒馆，补充资源更换同伴存档都可以，等再调查传送阵就可以传送到当前最深的进度了图29。

03最终连战前完成整备

突破完4-6的BOSS后再往下走就是最终BOSS战了，一直向右走尽头有存档水晶，进门之前会告知无法再回头，进门后开始BOSS五连战。

04处理杂兵与同伴属性支援

第一场有上下两个球，位置会不断左右交换。注意本体接触也会造成伤害。

第二场面对飞船形态的敌人，避开中间激光；可用失重奥义在上方寻找输出位置。

第三场优先消灭杂兵，尤其要及时处理会造成中毒的绿色敌人，再集中攻击首领。

第四个BOSS是个水晶，血量非常的高，这个BOSS会有同伴的帮助，隔一段时间地面上就会出现两个属性标志，触碰对应的属性出发对应同伴的攻击技能图30。

05优先处理持剑手与十字激光

随后进入最终首领战。优先攻击右侧持剑的手，减少十字激光的威胁；顺时针激光可在底部随轨迹向左移动，必要时用后撤的无敌时间回避。胜利后继续观看剧情，恢复自由活动后回家。若此前已恢复阿努莉斯的记忆，可再次挑战查看变化后的结局。
