火山再探索：宝石回收与贤者塔

攻略整理：GAME NOTE · 更新于 2026-10-22

GAME NOTE CLASSIC · GUIDE LIBRARY神之天平
ASTLIBRA
Revision

重新穿越火山，回收攻击宝石并前往贤者塔。

本页涉及后续剧情与结局分支，建议到达相应进度后再阅读。

  1. 会合盖乌，重访火山守护兽
  2. 击破火球并寻找贤者
  3. 用跳跃与失重应对贤者塔战斗

01会合盖乌，重访火山守护兽

第二天醒来家里卧室的门可以打开了，这样就可以返回之前去过的地方了。前往酒馆发生剧情，再次与弥露对话开始任务。到达火山后前往区域5发生剧情，剧情后前往区域8有存档水晶，往右走进入BOSS战。还是它，这次水属性魔法发生了变化，1个水球变成了3个，因为小黑有魔法罩，水球在发动前调整站位让小黑站在离BOSS近的地方她可以完全抵挡，别的技能都差不多不多说了。

战斗胜利后前往区域16，靠右边下到区域17可以见到“元件宝石【攻击力】”图10。然后再往左边跳靠左下去进入区域21得到“元件宝石【适应力】”图11。之后前往区域25发生剧情，有存档水晶和大宝贝商店，向左前进到达区域23有存档水晶，进门进入BOSS战。

02击破火球并寻找贤者

这次没有小白远程只能近战了，BOSS的技能有一个变化，天上下降的魔法弹，如果放这个时候跑到最右边，魔法弹就打不下来了；四周扩散的魔法球这个直接贴近BOSS输出，一个是小黑的魔法罩一个是BOSS能打到自己的翅膀上基本不会受到伤害；横向平移的魔法可以把小黑站位放到前面主角空挥让小黑持续魔法罩。胜利后前往区域25、26、27进入BOSS战。

一如既往的难打，有两个机制搞清楚剩下就靠个人了，第一个BOSS周围的火球要先打掉，血量非常厚要反复打，打完才能靠近输出；第二个小黑的攻击是跟随主角攻击来的，所以主角空挥会让小黑不断攻击，她的攻击就是魔法罩和最后一下冰魔法，持续空挥让她保持魔法罩有助于挡BOSS的魔法；有个集中大量火弹攻击的魔法，这个可以用三段跳然后再按下方向键失重奥义，这样就可以回避了。

胜利后发生剧情，来到矿石镇周边，这里和第七章是一样的，进入洞窟有存档水晶和大宝贝商店，切换区域进入BOSS战。和之前打法一样没难度。前进进入矿石镇，这里有存档水晶，一定要存档。

03用跳跃与失重应对贤者塔战斗

前往贤者塔发生剧情进入BOSS战图12。建议把跳跃力提高和三段跳，BOSS全程几乎凭依技都用不了，小行星和破防的时候可以放一下，BOSS最厉害的技能是帕尔缇娜，这个光靠防御不太行，看到文字提示马上向上跳起来用失重奥义如图12，这样可以完美回避，其他的没什么难度。胜利后主角回到力斯帕达尔镇，剧情后回家发生剧情。
