残余的混沌

攻略整理：GAME NOTE

GAME NOTE CLASSIC · 游戏攻略资料库第一狂战士：卡赞

返回据点与特利斯坦对话接取。

  2. 埃拉梅因的笔记

  4. 罐子、无尽悲剧卷轴
  5. 首领战

01鬼石

  • 鬼石 1

上面的支线做完我们去做这张图的最后一个支线残余的混沌。

传送进来后保存一下，我们先回头看，回头地上有一个记忆可以吸取。

角落还有一个鬼石，从左边进去。

02埃拉梅因的笔记

  • 埃拉梅因的笔记

拿到这个鬼石后我们往主路走，前面有一个紫色的传送门。

传送过来后右边角落有一个白色的道具。

主路中间有一个记忆。

左边第一个光门旁边有一个紫色的道具。

接着会从传送门里面出来很多怪物，波次有很多，最后一个精英打败才会停止刷新。

精英怪打掉后前面的机关才可以互动。

开关互动了以后回去坐传送门。

传送过来后左边有一个宝箱。

接着往旁边的主路走，路边能发现收集品埃拉梅因的笔记。

03坦尼娅的实验记录（三）

  • 坦尼娅的实验记录（三）

再往前走，角落有一个记忆。

拿到后继续往主路走，尽头有一个开关互动一下。

开关互动后继续坐传送门。

传送过来面前就有一个收集品坦尼娅的实验记录（三）。

04罐子、无尽悲剧卷轴

  • 罐子精灵
  • 无尽悲剧卷轴

我们继续往主路走，上楼梯后左边有一个隐藏门。

里面获得红色的无尽悲剧卷轴。

角落的罐子里面有罐子精灵。

05首领战

接着出去往前走就是存档点了，保存一下准备打BOSS。

这次的BOSS是坦尼娅，也是小怪换皮，打到人会吸血，伤害够就不难打。

打倒BOSS后会触发一段和埃拉梅因的回忆，本章结束。
