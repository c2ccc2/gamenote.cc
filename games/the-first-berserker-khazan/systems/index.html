武器技能

技能点可用于解锁不同技能；后续按武器类别整理解锁条件和实际用途。

  • 技能点可用于解锁技能；不同武器的技能还需要按类别分别整理。
  • 正式推荐某项技能前，应核对解锁前置、实际效果与当前游戏版本。

技能重置

官方商店说明支持随时重置技能点。后续会补界面路径与具体操作。

  • 官方说明支持随时随地重置和重新分配技能。
  • 本站尚未核对具体菜单步骤；不会把技能重置与角色属性重置混为一谈。

死亡后取回 Lacrima

倒下后可以返回死亡地点取回失去的 Lacrima。具体失败条件与路线风险待实机核验。

  • 死亡后可返回倒下地点取回失去的 Lacrima，以继续升级。
  • 连续死亡等情况下的损失规则和具体界面提示仍待实机核验。

幻影形态

官方介绍称，击败敌人、使用特定攻击与技能可积累变身量表；详细触发与实战用法待补。

  • 官方故事页列出的量表来源包括击败敌人、Brutal Attack 与 Spirit 技能。
  • 量表满后可在限定时间内变身；变身期间受到的伤害会扣除幻影形态量表而非生命值。

新游戏＋与终极挑战

通关后可进入新游戏＋，另有终极挑战模式。模式解锁条件、继承内容与奖励将分别核验。

  • 官方列有新游戏＋和终极挑战两个后续游玩方向。
  • 终极挑战包含不同规则的首领挑战；其属性与装备重置规则应与新游戏＋分开说明。
