巨剑配装：猩红恶鬼与蓄力衔接

攻略整理：GAME NOTE

GAME NOTE CLASSIC · 游戏攻略资料库第一狂战士：卡赞

装备与投入方向

  • 核心套装为猩红恶鬼，卷轴在隐士山脉流程。目标六件为护卫军巨剑、猩红恶鬼面具、护腕、上装、下装、脚镣。未到该章节时先使用当前等级合适的巨剑，不提前要求终盘套装。

  • 属性先满足生存和精力需要，再按当前武器实际补正选择输出属性。能够转换武器补正后，不能只根据“巨剑”两个字断言必须把所有输出点加力量。

  • 饰品优先填补精力与当前首领抗性；鬼神先用凯斯塔练习蓄力循环，习惯正面应对后可试沃弗瑞。

先形成基础循环，再加斗志技能

  • 先学会 Savage Momentum 与 Mortal Blow，再处理蓄力衔接和防守后续。所有可多级技能先测试基础级；不要为堆满一个尚不能命中的技能，放弃必要的前置动作。

顺序节点建议目标学习条件／作用
1Savage Momentum先解锁轻击分支：蓄力起手
2Mortal Blow基础级起步接在已开放的轻击派生后
3Armor Breaker1 级防御后轻击双斩；节点资料标示需求 2
4Combat Cadence先解锁闪避攻击进入蓄力衔接
5Heavy Pressure开放后学习缩短后续蓄力的压力
6Phantom: Night’s Veil有槽位后加入在安全窗口准备斗志强化
7Mortal Blow 后续节点按可用前置逐步补齐先在训练中确认新增动作

按破绽选择长度

  • 最短反攻：挡住已知的最后一击后，用 Armor Breaker，随后立即观察敌人是否恢复行动。

  • 标准循环：在足够长的破绽中，蓄力轻击 Savage Momentum → Mortal Blow。熟练后再用闪避攻击与 Combat Cadence 进入这条循环。

  • 长破绽或精疲力竭：先确认能覆盖蓄力和收招，再考虑加入斗志强化与后续重击；敌人离开有效范围时应停手。

套装条件必须真正触发

  • 猩红恶鬼的热血效果与蓄力、绝息斩效果分别有条件。不要把所有档位的面板加成当成始终同时生效。

  • 如果每次都因蓄力过久受击，先减少循环长度，再检查精力和装备重量。套装恢复不等于无限精力。

保存前做一次检查

  • 在同一敌人、同一难度下试短连段和长破绽输出；记录能否安全收招，而不是只看单次最高伤害。

  • 确认套装激活件数、装备重量、饰品抗性、鬼神能力和技能启用状态，再存为装备预设。终极挑战使用模式装备，不能照搬此战役配装。
