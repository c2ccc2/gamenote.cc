码头

资料持续整理中 · 更新于 2026-09-27

GAME NOTE CLASSIC · 黯井微光

★ 码头：区域图文记录

一、进入木制高台区域

码头探索以木制高台、阶梯平台和大段竖向落差为主。先沿平台层层推进，跳跃前确认目标平台是否有侧壁尖刺。木台下方也有空间，不把上层唯一可见的路线当成全部支路。

二、找到巴吉并完成初次对话

带圆窗与救生圈的室内节点可以遇到巴吉，画面对白提到船员失踪。先完整看完对话，再检查码头各个分支；这是寻找船员相关线索的起点，不把初次见面写成任务已经完成。

三、吊网与刺球之间穿行

一段高空通道中，吊网和带刺球形障碍交错排列，上下都有危险物。观察吊网与刺球之间的空隙，分段跳向安全平台。回收高处拾取时先规划回程，避免拿到东西后只能落入下方刺区。

◆ 紫色帐篷存档节点

木台上的紫色帐篷显示“游戏已保存”，可以作为探索多个分支时的回查节点。进入连续尖刺房间前，先从这里确认当前路线和补给状态，再沿已经走通的支路推进。

四、悬空刺板的安全落脚面

这里有几块悬浮平台，其中竖板侧面和下方大段地面覆盖尖刺。录像从上方跨越这些平台。落脚时要区分刺面与安全面，不要把竖板所有边缘都当作可攀爬墙面。

★ 用码头局部地图回查右侧分叉

地图画面显示码头已探索的浅紫色房间、右端人物位置与多个上下分叉，还能看到紫色节点标记。按人物所在房间向相邻支路逐个回查。图中仍有黑色区域，因此这是当时探索进度图，不是完整地图。

五、回程继续穿过吊网通道

录像回程再次经过吊网和刺球，解说提示从下方打开反锁连接。把首次经过与回程开门分开记录；开启捷径后再安排回收路线，避免仍按旧路线重复绕行。

六、沿水面的后段战斗

这场战斗发生在水面上的水平木栈道，敌人在主角左侧，远端地面仍有尖刺。利用可站立的水平空间调整距离，注意边缘及敌人的后续动作。该画面不显示明确名称，本轮不强行命名 Boss。

七、战后对白与场景变化

后段战斗之后出现倒地角色与“抱歉”的对白，场地由战斗状态转入剧情。此处记录实际战后节点，后续人物关系以完整对白为准，不单凭造型判断身份。

→ 回到巴吉所在房间

录像末段回到先前有圆窗与救生圈的房间，再次见到巴吉。探索相关船员支线时可以以此作为回访节点。当前截图没有任务完成提示，因此不据此承诺任务奖励或水上载具已经解锁。

★ 进入深渊前的码头补给：区域图文记录

→ 深渊之前先回码头帐篷

深渊录像开头仍在码头紫色帐篷旁，显示存档提示；字幕提示补买油瓶。把补给节点保留在码头章节，随后再转入水下载具探索。录像标题不代表从第一秒起就已处于深渊。
