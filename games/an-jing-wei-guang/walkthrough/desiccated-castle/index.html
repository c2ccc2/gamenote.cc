GAME NOTE CLASSIC · 黯井微光

★ 荒堡：区域图文记录

一、紫色帐篷作为探索起点

录像从城堡内部的紫色帐篷附近展开，画面显示“游戏已保存”。先以这个节点整理回程路线，再向周围房间分支探索。这里保留既有 Desiccated Castle 目录，中文“荒堡”沿用录像标题；正式中英地名对应仍需区域标题画面复核。

◆ 石头遮挡的收集支路

一处低顶房间内，录像解说指出上方有被石头遮住的收集物。检查地面开关或可互动机关后，再观察上方路线变化；不要只清理当前地面上的拾取。该帧没有物品菜单，因此不填具体名称与数量。

二、尖刺竖井的计时挑战

计时挑战中，主角沿狭窄竖井上升，两侧墙面都有尖刺。录像字幕在此提示朝左侧攀爬。按当前画面可用的安全墙段控制移动，避免只盯着计时器而碰到侧壁尖刺。截图不是挑战完成凭据。

三、悬挂木舟与投射物场景

城堡房间里出现吊在链条上的木舟形目标，周围有蓝色瓶状投射物。观察吊挂物的移动及投射方向，留出横向走位空间。此处不将外形相似的角色直接判为 Boss，也不把动画当作已完成 NPC 任务。

四、拾荒者提到下一站码头

随后对话框明确标为“拾荒者”，其对白说这里忙完后将去码头找姐姐。这是从荒堡转向码头的重要剧情线索。先完成当下对话，再回查尚未走过的房间；一句未来计划不等于 NPC 已经在码头出现。

◆ 链条机关旁的高处书页

一处链条机关房间左上方可以看到发光的书页，左侧墙壁和突出平台覆盖尖刺。先从安全高台观察跳跃距离，再绕开刺面接近书页。此处确认书页所在画面，不把尚未打开的书页菜单写成特定故事章节。

五、回查低层通道的拾取节点

后段路线回到有草地平台和低顶结构的房间，左侧平台旁出现绿色图标拾取画面。按小地图对照回程支路，检查平台下缘是否仍有遗漏。绿色图标没有配套名称框，暂只记录拾取节点。

※ 月亮背景房间的上下层差异

月亮背景的房间中，上方独立平台布满尖刺，下层则有可连续通行的地面。优先沿安全下层确认出口，再考虑高处支路；不要把每个看得到的平台都当作可停留位置。

六、水面石碑的微光对话

水面石碑旁的对话框显示说话者“微光”，内容提到一个早已被遗忘的诅咒。这是实际剧情对白节点，不是已经解锁某个隐藏结局的证明。整理结局条件时应另核后续触发步骤。

→ 巢状平台与后续教学

录像随后到达巢状平台，主角旁出现发光教学物。后续片段进入独立的教学空间。先完成这里的互动，再按游戏提示尝试动作；本轮没有清晰读取能力名称，因此不覆盖既有能力目录或编写新的正式名称。
