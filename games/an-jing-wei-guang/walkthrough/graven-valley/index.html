墓谷

资料持续整理中 · 更新于 2026-09-27

GAME NOTE CLASSIC · 黯井微光

★ 墓谷：区域图文记录

一、钟形机关与虚线平台

墓地地形中出现吊钟，下方右侧可以看到虚线标出的平台位置，地面及侧壁都有尖刺。不要把虚线位置直接当作当前可站立地面；先检查机关与平台变化，再安排穿越路线。

★ 用浅色区域图核对支路

此处打开地图，可以看到浅色区域内的多条分叉，以及左侧红色区域连接。人物标记位于右端，附近还有斜挂的小平台。按实际已探索房间逐段核对，不把两种颜色的区域混成一个地图章节。

二、木台上的报幕员

有王冠装饰的木台是重要剧情节点，首次经过时对话框标为“报幕员”，台上还吊着笼子。先看完对话，再检查舞台左右的通道。此时是剧情对话画面，不提前写成已经击败此处 Boss。

三、笼中埃格伯特的对话

再次来到吊笼木架处，画面中的对话框明确写着“埃格伯特”。两个吊笼中的角色外形不同，后续整理任务时应分别记录。此帧确认对话与位置，不能单独证明角色已经获救。

※ 地面目标与飞行敌人同场

一处低矮通道里，地面目标上方同时有两只飞行敌人。录像解说的处理思路是优先清理空中威胁；接近地面目标前先给自己留出走位空间，避免被上下夹击。这里不把敌人的外形当成正式名称。

四、墓碑之间回查高低差

这一段在连续墓碑与阶梯平台之间移动，右端还有木架结构。按已走过的水平路线检查高台侧边与下方支路；准备跳跃前观察天花板，避免把低顶通道当作能直接向上攀出的空间。

五、重返舞台后的战斗节点

录像后段再次来到带王冠的舞台，台前出现与先前对话不同的巨大怪物形态。把初次报幕、吊笼对话与此时战斗前画面按顺序区分，避免在流程说明里混写为同一次到访。

★ 舞台战斗：站位集中在中央平台

战斗画面中，主角站在中央木板，两侧地面覆盖尖刺，巨型敌人有多条手臂并放出红色球状攻击。注意平台可站立宽度，优先观察接近身体的球状攻击，再寻找输出空档。不把解说者的个人回合数写成固定阶段或必胜次数。

★ 墓谷回访：区域图文记录

◆ 码头之前：墓谷吊钟与机关回访

本段录像开头仍在墓谷，先回访吊钟附近。画面中钟体落在主角上方，高处的透明平台连接了左右地形。把这里记在墓谷，不因录像名为“码头”就把这一段改归码头地图。

→ 从反锁通道另一侧继续

回访后，录像来到此前反锁通道的另一侧，字幕明确说明这一连接关系。两边地形由斜向木板与小平台衔接，下方还有支路；先对照当前小地图，再向上前往码头方向。
