沼泽

攻略整理：GAME NOTE · 更新于 2026-09-27

本区域要点

推进目标
检查入口竖井和下层支路，推进虫群战与攀爬教学。
能力 / 使用限制
攀爬受耐力限制，站在坚实地面可恢复耐力。
回头探索
取得攀爬后，回到紫色帐篷附近检查高墙与上层支路。
NPC
伊尔达 · 途中与营地篝火旁的两处对话。
Boss
虫群

地图 · 攀爬

路线速览

  1. 入口竖井与下层支路
  2. 伊尔达营地与回程地图
  3. 虫群战斗
  4. 攀爬教学与高处回访

★ 沼泽：区域图文记录

一、沿入口竖井下落

进入沼泽后，先检查入口附近的竖向通道。沿带水泡的竖井落到下层，再打开地图核对上下通道，不要漏掉下层支路。

二、平台右侧的低处也要检查

从草地平台右侧跳下，在底部靠近罐子的位置继续探索并检查发光拾取物。上方还有敌人，先观察落脚点再下落。

三、途中与伊尔达对话

在有巨大车轮背景的平台上与伊尔达交谈。看完关于上方宫殿的对话后，再检查周围通道。

◆ 竖井内的饰物点

在窄竖井向上弹起时，可以取得饰物点。用截图中的小地图对照房间位置，检查这条上行支路。

四、带尖刺的计时挑战房间

进入砖墙计时挑战房间，先观察平台距离与地面尖刺。选择安全落脚点，再连续跳跃推进。

◆ 小平台上的发光拾取点

返回沼泽时，检查狭窄通道中央小平台上的发光拾取物。留意顶壁高度，站稳后再跳向下一处平台。

五、营地篝火与伊尔达

在营地区域再次与坐在篝火旁的伊尔达交谈。探索路线上的对话与营地对话位于不同节点，两处都可以查看。

★ 用局部地图核对回程支路

打开地图，对照浅黄色沼泽房间、右侧蓝色区域与人物位置。回查横向通道和向上的支路；黑色部分仍未探索。

六、后段战斗：注意背景头骨的冲撞

战斗中留意移入场内的大头骨。观察其移动方向，给自己留出横向躲避空间，不要只盯着主角附近的小目标。

※ 地面威胁与空中虫群要一起看

地面头骨、上方虫群和右侧飞来的圆形目标会同时构成威胁。移动前一起检查地面与头顶，避免被上下夹击。

七、获得攀爬提示后再回头补探索

战后在巢状平台完成攀爬教学：贴墙按住跳跃即可攀爬。体力有限，站在坚实地面会恢复；途中应寻找可站立的平台。

→ 回到紫色帐篷附近检查高处

返回紫色帐篷保存游戏。利用新获得的攀爬能力，回查此前难以到达的高墙和上层支路。
