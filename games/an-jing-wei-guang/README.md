# GAME NOTE CLASSIC

本目录 HTML 由 `scripts/build-classic.cjs` 生成，请不要直接修改。

内容源与图文组件用法见 `content/games/an-jing-wei-guang/README.md`。修改 `data.json` 或统一更新数据后，在仓库根目录运行 `node scripts/build-classic.cjs`。

共享结构：ClassicSidebarNav、ClassicArticleLayout、ClassicBanner、ClassicInfoTable、ClassicImageBlock、ClassicPager、ClassicSectionHeading、ClassicNotice 对应生成器函数与 scoped classic CSS；不影响主站主题。
