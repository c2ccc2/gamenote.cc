血色森林：红叶林道至花千笑

花千笑：雾中木台 →

进红叶林后找栏杆旁立着鹤形装饰的木台。走到鹤旁，与蓝衣的「虚空幻象」交谈，听完这段对话再沿林道推进。

沿红叶林里的宽木阶上坡。木阶右边能看到斜插的木桩，左边是贴坡搭建的木板。沿林道走到雾中有栏杆的宽木台，接着会触发花千笑的对话和战斗。

花千笑拉开距离后也会挥出横向白色剑光。看到他起手时先停下追击，留出躲闪空间，等剑光扫过再接近。尽量在木台中央交手，避免贴着栏杆调整站位。

把花千笑打到终结阶段后完成终结。画面出现水墨「斩」字，随后可在右侧看到战后奖励提示。

血色森林：挂笼小道与沿途宝箱

挑战荆野前，把三种药草带回悲泣溪谷据点交给玉儿。击败荆野后，未完成的采药支线会失败。

查看任务条件 → 玉儿采药路线 →

荆野：红叶空地的骑战 →

花千笑之后进入一处岩壁夹出的空地。找火堆和头顶用铁链吊起的木笼，靠近火堆一侧会进入笼下的对话。

找红草坡下那片泛绿的低地，两侧有木架和残栏。下到低地打开灰色箱子，右侧会显示获得「黑石碎片」。开完箱就离开低地，实录中角色在这里掉了血。

还有一个箱子在贴着岩壁的木平台上。认红底金纹的箱身，打开后可拿到「斩骑符」。装备说明显示，它能提高对骑兵类敌人的伤害 25%。

沿小道走进红叶空地，看到骑马的荆野就先往场地中央拉开。马抬起前蹄时，先向侧面闪开，等前蹄落地再看他有没有接招；等到马从身边冲过、开始掉头时，再贴侧面打短连段。前面拿到的斩骑符也可以在这场战斗前装备。

战后找场地外沿的木拒马。从拒马旁的土路往崖边走，看到横跨峡谷的绳桥，就到了通往飞贼营地的方向。

挂笼小道：黑石碎片与斩骑符 →黑石碎片：挂笼小道低地灰箱 →斩骑符：临岩木平台红金箱 →

血色森林：飞贼营地的通道与对话

进入营地后沿木屋和帐棚之间的落叶通道走。前方横跨两侧岩壁的瓦顶门架很醒目，可以用它辨认营地内的主通道。

在营地里找敞口木棚，棚下站着红衣蒙面人和一位黄袖女子。走近棚口与他们交谈，再离开营地。

快手张委托：分区宝物与交付 →快手张的五处藏身地 →

血色森林：悬崖山舍的地下入口

进山舍后找摆满陶罐的木架。木架与矮石墙之间，木地板上有一条往下的开口，从这里下到屋底。

在下层沿木板通道找火把照亮的铁栅栏。贴着栅栏坐着一名黄头巾人物，旁边还有一只箱子。走到火把下时停下来查看这两处。

血色森林：镜林铁狂战与蓝花对话

铁狂：镜林岩壁空地 →

进入岩壁旁的空地后会遇到铁狂，场边的木梯可以用来辨认战场。铁狂砸地时会扬起一片尘土，近身打完一轮就留出闪避空间，等他收招再靠近。

战后继续探索，留意崖边木板上、成排绳索旁的发光蓝花。靠近查看，可以听到铁鬼提到用本门拳法去找他。

另一处蓝花在石墙边的大树根下，旁边有石灯。靠近这朵花查看虚空的对话。

镜林深处：白赤练的蓝花

挑战白赤练前，先完成据点和飞贼营地的限时支线，并在大桥找兰兰接取白山派支线。

查看任务条件 → 四名飞贼的救治路线 → 白山派支线接取路线 → 羽弓交付路线 → 队长命令与据点回报 → 四斧文书的七处位置 → 飞贼营地三道问答 →

在两盏吊灯之间找到发白光的林道口。先查看入口前地上的蓝花，听白赤练提到「寒号」留下的东西，再往亮处走。

回访杀气塔：雪中入口与塔内双首领

查看杀气塔原石与回访路线 →

铁鬼与玉妖：杀气塔双首领 →

后期回访时，从积雪覆盖的宽石阶上到木建筑入口。塔内沿有红光的木楼梯推进，最早开放条件仍待核对。

进入有大火盆和金属格栅的房间后，画面同时显示铁鬼和玉妖的血条。交手时留意两者位置，避免在火盆边背对另一人。

「三面混沌」还有战斗收尾。戏梦山庄集齐三朵后，后期实录在雪中丝线缠绕的巨树旁击败三面魔偶，战后获得武器铸魂材料「混沌双钺」，可用于黑伤双刃铸魂。

血色森林杀气塔：玉妖切磋与指定配装 →铁鬼委托：遗冢地的大坟 →榕树挑战：五处入口 →

三面魔偶：雪中巨树与战后奖励

三面魔偶：雪中巨树与战后奖励 →

在戏梦山庄收齐三朵记忆后，回访血色森林。雪地上方有大量丝线汇向一棵挂着灯笼的巨树，以树和垂落的丝线辨认战斗区域。

同屏出现「混沌」和「寒水」两条血条时，拉到空地，让两个敌人尽量都留在视野里。看到其中一个带着紫光贴近，先横移避开，再观察另一个的站位，确认有空档后才补短连段。

完成终结后，装备界面弹出单手武器「刺骨混沌」。收起武器界面后继续确认物品提示，还会获得铸魂材料「混沌双钺」，用于黑伤双刃铸魂。
